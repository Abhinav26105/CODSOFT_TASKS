# 🎯 Task 1 - Number Guessing Game

## Description

The Number Guessing Game is a console-based Java application where the computer generates a random number and the user tries to guess it.

## Features

- Generates a random number.
- Allows the user to enter guesses.
- Provides hints when the guess is too high or too low.
- Limits the number of attempts.
- Calculates the score.
- Supports multiple rounds.
- Displays the final result.

## Concepts Used

- Java
- Scanner Class
- Random Class
- Loops
- Conditional Statements
- Methods
- Variables

## File

Task1_NumberGame/src/NumberGame.java

# 🎓 Task 2 - Grade Calculator

## Description

The Grade Calculator is a Java application that calculates a student's total marks, percentage, and grade based on the marks obtained in different subjects.

## Features

- Accepts student information.
- Stores subject details.
- Calculates total marks.
- Calculates percentage.
- Determines the student's grade.
- Displays student performance.

## Concepts Used

- Classes and Objects

# ▶️ How to Run

## Prerequisites

Make sure Java JDK is installed on your computer.

Check Java version:

    java --version

Check Java compiler:

    javac --version

---

# Clone the Repository

    git clone https://github.com/Abhinav26105/CODSOFT_TASKS.git

Move into the project directory:

    cd CODSOFT_TASKS

---

# Run Task 1 - Number Guessing Game

Go to the source folder:

    cd Task1_NumberGame/src

Compile the program:

    javac NumberGame.java

Run the program:

    java NumberGame

---

# Run Task 2 - Grade Calculator

Go to the source folder:

    cd Task2_GradeCalculator/src

Compile the Java files:

    javac *.java

Run the program:

    java GradeCalculator

---

# Run Task 3 - ATM Interface

Go to the source folder:

    cd Task3_ATMInterface/src

Compile the Java files:

    javac *.java

Run the program:

    java Main
